# Defragmenter 1.8.0-244

Fixes the remaining ZFS qualification and Test Media diagnostic defects from the physical-media run.

- Both ZFS metadata lookup and file-fragmentation traversal validate indirect-block geometry only when the dnode actually has indirect levels. Direct trees do not shift by an unused `indblkshift` value.
- Unsupported level counts, missing root pointers and unsupported indirect shifts report the actual field values. Indirect blocks must match the declared geometry; checksum and allocation bounds remain enforced.
- Successful ZFS/UFS formatting followed by native analyser rejection reports **Qualification failed**. Creator or image-copy failures retain their own format-stage result.
- The Test Media page scrolls with both detail panels expanded, and its initial size is bounded to the monitor work area.
- **View log** opens a separate scrollable diagnostic window with **Copy log**. Failed workers open that window automatically after their final buffered output has been drained.
- Native C regression coverage exercises direct and indirect ZFS trees, malformed geometry, the final output after GTK's 64-line drain limit, status display, clipboard copying and the real small-screen window layout.

The native changes pass warnings-as-errors compilation and focused ASan/UBSan checks. Publication requires the full hosted quality and sanitizer gates. A rerun on the user's physical test disk remains necessary to establish that disk's complete 21-slot result.
