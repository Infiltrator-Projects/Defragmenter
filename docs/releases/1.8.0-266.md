# Defragmenter 1.8.0-266

This release publishes the first-party UFS2 Test Media creator already integrated into main. The previous qualification passed all 46 CTest cases and ASan/UBSan, but the release audit still referenced the source from before those changes, so the release gate correctly rejected it.

The incremental review now records source and release-governance baseline `7424678c7adc283da5e14cf52b426afcce0261d7`. It covers the bounded native creator, its mandatory build/install and resolver integration, removal of the external makefs prerequisite, and the end-to-end creator/worker release test. Filesystem mutation and recovery engines are unchanged. Both former UFS branches were compared against main and their changes are already integrated with identical file contents.

This release changes only VERSION and the audit/release records. The exact release commit must pass the complete project quality gate and ASan/UBSan lane, then build, test, checksum and publish its Debian package and native installer once. The audited-source and governance drift checks remain enforced. Completion also requires the same Debian package version and digest to appear in the public Software Centre and APT index.
