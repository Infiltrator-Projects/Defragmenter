# Defragmenter 1.8.0-251

This release consolidates the current physical-filesystem qualification work into the authoritative `main` line.

Btrfs internal reserved roots are interpreted using their on-disk signed object-ID semantics, UFS placement honours cylinder-group allocation geometry across multi-group volumes, and secure journal paths support root-owned sticky ancestors while continuing to reject ordinary shared-writable parents.

Associated native and filesystem qualification coverage is included. Temporary branch-only CI scaffolding is not part of the release source.
