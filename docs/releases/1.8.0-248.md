# Defragmenter 1.8.0-248

Fix a premature read-only EXT failure when a refreshed group descriptor fails its checksum during an update but a subsequent read is valid. One EXT function now retries that descriptor read up to three times, retaining the previous descriptor until a replacement passes checksum verification.

The native C regression failed on 1.8.0-247 and passes with the correction for both block and inode bitmaps. Persistent invalid descriptors and bitmaps remain rejected; writable snapshots and I/O error handling are unchanged. Normal and ASan/UBSan targeted checks passed. Publication requires the exact-head full and sanitizer gates.

The user's physical EXT failure remains unverified. This iteration preserves the approved interface, MB fonts, Common pin and existing filesystem support.
