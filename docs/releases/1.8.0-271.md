# Defragmenter 1.8.0-271

A restarted desktop can reach native Recover from an existing journal when an
interrupted source cannot pass normal analysis. The native recovery worker
still validates journal schema, target identity/capacity, staged bytes and
transaction phase before writing; new layout operations retain their exact
analysis and writer-qualification requirements.

Btrfs exact analysis now verifies primary-superblock and consumed-tree CRC32C
checksums and propagates failed filesystem-tree scans. Unknown checksum
algorithms and malformed allocation items are refused explicitly. Mutation
algorithms, journal schemas and recovery phases are unchanged.

The physical allocation raster uses one or more whole native allocation units
per mapped device pixel. It combines adjacent cells for large maps and leaves
surplus canvas unused for small ones. FAT clusters are not expanded into sector
pixels. One pure geometry contract supplies painting and integer density
captions, replacing the former magnification machinery.

APT observation follows the canonical Debian package and verifies the exact
qualified version and SHA-256 in both public catalogue and package index.
Behavioural fixtures exercise successful observation, stale versions and
altered digests. Maintained dependency, shared-font-cache and update
contracts now match the implementation.

The reviewed source and release-governance baseline is
`62de3845c5b7d685ffa39b099743287a707f461b`. The exact versioned release head
must pass the complete mandatory quality/sanitizer gates and publish the
once-built, checksum-bound Debian and local installer artifacts. Physical
power-loss qualification is separate environment-dependent evidence.
