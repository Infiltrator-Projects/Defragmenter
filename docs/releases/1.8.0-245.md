# Defragmenter 1.8.0-245

Restores the colourful Test Media interface and corrects the typography and layout regressions visible in 1.8.0-244.

- Restores the blue-to-purple hero, cyan device border, coloured summary icons/cards, filesystem-family edges and status pills, and distinct cyan, purple and red operation controls.
- Uses Common's MB Corpo A brand face explicitly for the shell/page headings and MB Corpo S regular/bold for the interface. Secondary text is enlarged to 12 pixels, with 14-16 pixel labels and 20 pixel summary values.
- Lets the complete filesystem grid grow inside the page instead of clipping it behind a fixed-height inner scroll area. Operation descriptions and long filesystem results wrap at narrower widths.
- Accounts for the custom title bar when sizing the window to the active work area, while retaining whole-page scrolling and accessible diagnostics.
- Preserves the 1.8.0-244 ZFS fixes, final worker-output draining, failure log dialog, View log and Copy log.

Local validation includes a warnings-as-errors native build, real GTK rendering at 1920x1080 and 1024x768, and resolved MB font-family/weight checks using the verified fonts from the released package. The GTK regression checks font sizes, operation icon colours, all 21 grid entries, full window bounds and expanded-panel scrolling; it also passes ASan/UBSan. The full hosted quality and sanitizer gates remain required for publication. No filesystem-engine, disk-write, transaction, recovery or target-safety behavior changes in this release.
