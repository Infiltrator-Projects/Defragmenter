# Defragmenter 1.8.0-243

This release simplifies the native Test Media interface without changing filesystem-engine or write-safety behaviour.

- Replaces the visually noisy gradient-heavy Test Media treatment with flat Common-owned surfaces and thinner neutral borders.
- Removes decorative filesystem-family rainbow colouring; semantic colour is now reserved for actual status and destructive meaning.
- Reduces hero, summary-card, icon-well and filesystem-tile visual weight so the qualification matrix is the primary information surface.
- Gives Qualify Production Engines and Verify After Defrag one consistent primary-action treatment while retaining red for Build Test Disk.
- Simplifies the progress strip, technical details and log surfaces while keeping all existing qualification data and controls.
- Preserves the GTK semantic-class isolation that prevents host themes from washing disabled action buttons into pale unreadable slabs.

The audited production-source baseline for this release is `f3608bb0deefa64a348ebec783a6f3909bba662b`. That baseline passed warnings-as-errors compilation, native GTK smoke testing, all 46 CTest cases, ASan/UBSan and the Local Linux/heavy qualification lane. No filesystem analyser, writer, placement, transaction or recovery semantics changed in this UI-only release.
